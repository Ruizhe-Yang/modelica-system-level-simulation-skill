# MOSAIC v0.9｜项目工作约定模板

先读本轮任务和project_contract.json。默认AUDIT只读；明确模式、允许/保护集合和终止条件。R必须、S建议、F参考，项目选用项单列，不继承案例的运行预算、文件删除清单或工具权限。

TB/SB/AB有效本层只声明、静态配置和connect；BU禁止connect及独立运行子实例，LU保留原MSL。优先标准组件与可导航装配，不把系统藏到大BU，也不改角色标签掩盖违规。

复合接口按业务集成，MSL成员在局部白箱分接；全部真实connect在其声明层可见。删除/改向/改变访问范围/重写connect是INTERFACE_REFACTOR，需要语义核查，不是图形任务。

DOCUMENTATION_ONLY仅改类级说明与声明string-comment；CONNECTION_COLOR_ONLY仅改真实Line.color；FORMAT_ONLY保护全部字符串、注释、计算/图形Token和版本文字。其他非.mo文件精确列白名单并单独审查；保护器不能删除全部annotation。

MSL及派生接口沿真实继承用默认线色；自定义整体使用已审查主色，其中MSL成员仍用本族色。图标/语言/目录是作者配置，选用后成为项目要求，不改通用等级。说明随成员同步，生成器不回灌旧文稿/接口/颜色。

只在授权目录创建独立候选。源码、编译展开、动态、原生GUI分别报告；未执行保持NOT_RUN/NOT_CHECKED。启用最终完整回归后，失败继续必要诊断修复；不造结果、不缩合同或改容差。默认一份Markdown累积总结，不额外制作仿真数据图，不推送仓库、不安装软件、不删除旧skill。
