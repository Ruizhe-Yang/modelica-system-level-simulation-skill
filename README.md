# MOSAIC-skill v0.8

**Modelica 总体建模规范与工程维护技能。**

Model the Whole as MOSAIC.

入口 `SKILL.md`，技能名 `mosaic`，发布元数据 `0.8.0`。用于新建/细化总体模型，或对成熟工程进行文档、图形、配置和诊断维护。包含完整 **M01—M36（26必须、9建议、1参考）**、五角色与白箱逐项清单、24类 MSL 接口参考、A/B/C/D 专项参考和可执行静态辅助工具。唯一具体项目案例为 12UCubeSat。

## 安装与调用

把 ZIP 内的 `mosaic` 文件夹放在**一个**所需位置：项目 `<repo>/.agents/skills/mosaic/`，或用户 `$HOME/.agents/skills/mosaic/`。不要把带版本号的 ZIP 目录再套入一层。Codex 本地发现方式参照 OpenAI 官方 Build skills 文档（2026-10-10核对）；未显示时重新启动客户端。其他 Agent Skills 宿主按其加载能力使用。本包不是账号插件安装包，不声称直接上传即可在所有客户端生效。

```text
使用 $mosaic。基于当前工程，仅清理 Documentation 中重复的连接统计、查看教程和辅助更新尾语，保留实际限制与变量注释。核对 MSL/派生接口连线原色，自定义整体线色与接口主色一致。不得修改物理方程、参数、初始化、接口字段、connect 端点和其他图形。输出新候选与精确保护差异。
```

新建或行为修复改用 NEW/REFINE 并明确用途、时域、接口、配置、验收与预算。`TB/SB/AB` 必须遵守白箱分工；仅辅助任务不会因为更详细的角色标准自动改动现有结构。

## v0.8 的主要补充

| 内容 | 具体变化 |
|---|---|
| 模型分类 | TB/SB/AB/BU/LU 各有必须包含、允许构成、禁止混入、说明重点和检查卡 |
| 白箱语法 | 18类语法/内容逐项核对；含继承、绑定、初始化、静态连接模板、上下文与注解 |
| 文稿 | 去掉通用套话，保留真实限制；类说明中文用途，模型树只显示一份英文类名 |
| 线色 | 追溯派生与嵌套成员；MSL默认色与自定义整体主色分开；实际连接与装饰线分开 |
| 工具 | 只读角色和线色核对、文档候选清理、精确连接线颜色豁免、生成钩子防回退 |
| 品牌 | 原 MOSAIC LOGO 与蓝白文档视觉；不改 MSL 物理接口颜色以配合品牌 |

## 文件入口

先读 `SKILL.md`，再按任务读取 `references/standard.md` 与 `references/model_roles.md`。接口/配置/文稿/图形/验证/Codex 各自独立参考。`assets/` 提供角色映射、合同、文稿目录、报告模板及原品牌图；`scripts/` 提供真实可运行工具；`tests/` 提供自测；`examples/12ucubesat.md` 解释一个已认可工程的使用方式，不作为其他项目参数源。

核心工具使用 Python 3.10+ 标准库；读取 MAT 元数据时另需 numpy/scipy。编译与仿真须本机实际 Modelica 引擎，不能由本包静态工具替代。

```bash
python -m unittest discover -s tests -v
```

本版实际完成的工具测试和静态范围见 `VALIDATION.md`。安装不会自动运行脚本、联网、修改模型或删除旧 skill。旧工作迁移见 `references/upgrade.md`。
