## C.1 终止条件按任务分类

**新建/行为细化/接口重构。** 已授权结构、输入闭合、配置消费和结果完整性完成；适用R和项目硬检查全部参与判定。接口语义变更必须核对展开网络、状态、初态和结果路径。项目启用最终完整回归时，必须在最终候选上完成；失败后继续必要诊断修复，不能以已跑一次为停止理由。条件不足则如实交付候选、阻塞和最后可信版本，不伪造通过。

**文稿/线色/图形。** 所有目标范围已处理，旧成员/套话不再回灌，名称不重复，颜色有类型/审查色表依据，修改限定在允许节点；其他字段、连接、初态和结果设置保持。图形坐标/原生GUI的证据不能由文本比较替代。

**纯排版。** 新候选与基线的计算/图形Token、字符串、普通注释、语句顺序一致；同一格式操作再次执行无新变化。保守工具只整理空白，不承诺完整语言缩进。FORMAT_ONLY不允许改根版本或类说明。

**只读审核/结果诊断。** 输出位置明确的事实、疑点与未知项，不写入模型。没有数据先核对原保存、格式和路径；不要把全零轨迹或导出异常自动归因于界面。

## C.2 工具入口和可证明范围

| 工具 | 实际工作 | 不证明什么 |
|---|---|---|
| audit_project.py | 源文件/声明/依赖线索盘点 | 完整语法、有效展开与运行 |
| audit_roles.py | 显式角色映射、有限结构及BU connect检查 | 全部继承、重声明、所有运行类型 |
| audit_connections.py | 枚举源级connect、缺Line/隐线/零长/零尺寸及显式画布问题 | 编译后连接集、变换后完整端点或GUI显示 |
| connection_colors.py | 固定4.0.0有限族及端点解析，已审查自定义主色 | 未支持库族、新版本、完整因果性 |
| verify_change_scope.py | 分模式保留Token与精确图形/文稿节点豁免 | Modelica可解性和数值等效 |
| format_modelica.py | 字符串/注释之外的尾空白和冗余空行候选，Token和幂等检查 | 完整AST重排/所有语法的缩进格式化 |
| clean_documentation.py / enrich_documentation.py | 指定文稿清理/已审查目录生成候选 | 资料未提供的语义自动正确 |
| inspect_result_metadata.py | 读取实际XML/MAT元数据 | 重新编译或仿真 |
| run_guarded.py | 获授权命令及其进程的时间监督 | 平台可用性与任务验收 |

v0.9新辅助任务优先使用verify_change_scope；旧verify_aux_only留作生成钩子兼容。颜色写入需显式--apply及--msl-version 4.0.0，自定义主色需reviewed=true；不解析或冲突时拒绝写入。不自动联网、安装软件或改变宿主设置。
