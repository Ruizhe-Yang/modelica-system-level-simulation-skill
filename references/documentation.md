# 附录 D｜Documentation、类说明与结果注释维护参考

## D.1 写给实际使用者，而不是写给补丁审计器

建议按“这个类干什么 → 从哪里用 → 怎么配置和接入 → 内部怎样实现 → 有什么真实限制”的顺序写。每个类只出现与自己有关的部分。没有状态的接口不写“状态初始化”；没有参数的纯转发类不硬凑参数表；大矩阵给资产位置与轴含义，不把全部节点堆进说明页。

| 类种类 | 建议保留的最小内容 | 可以集中到项目根说明的内容 |
|---|---|---|
| 根 package | 工程用途、MSL 依赖、准确入口、离线配置方式、主要包导航 | 安装、打开工程、运行、结果窗口操作、版本历史 |
| TB | 实验目的、活动构型、任务/初态范围、主要输出语义 | 每一步 GUI 点选、通用文件格式教程 |
| SB / AB | 组成单元、公开边界、关键配置、实际集成假设 | 全局统计、与当前类无关的审计过程 |
| BU | 本构/算法用途、输入输出、参数、状态/初态、真实有效域 | “本次没有改变方程”的逐类免责声明 |
| LU / 继承类 | 原始基类、静态改了什么、公开接口与使用差异 | 复制原库全部内部字段或重复原库长文 |
| connector | 成员、单位/维数、方向、时间、介质/参考系、生产消费责任 | 重复整机连接数量 |
| record / type | 字段、默认/派生关系、码表、消费者、编辑源 | 运行截图和无关仿真说明 |
| function | 输入顺序、输出含义、算法概要、有效域/超界方式 | 宣称已编译或已实物验证的固定套话 |

**不再逐类生成三类冗余内容。** “连接与责任”作为重复连接统计段删除；“仿真后如何查看”作为通用教程段删除；“Documentation 辅助更新……”作为发布免责声明删除。实际接线含义仍在接口/内部组成中保留，实际“使用边界”仍保留。许可、来源、物性假设和工作域不是应该删除的废话。

## D.2 类说明不是完整模型树标签

Modelica 声明的 string-comment 是类的说明，目标建模器通常已经同时显示类名。针对当前模型树显示习惯，中文用途只写一次：

```modelica
package SpacecraftProject "立方星总体仿真"
  // 包内按实际模型组织。
end SpacecraftProject;

model CompleteMission "完整任务仿真"
  // 这里保留真实模型声明和连接，不为显示名称改标识符。
end CompleteMission;
```

目标模型树显示为 `CompleteMission（完整任务仿真）`。不要将 `"CompleteMission（完整任务仿真）"` 再写成类说明，否则可能显示双重英文和嵌套括号。改变类说明不改文件名、within、package.order、引用路径、变量名或 Icon 中的 Text。不同工具选择不同展示模式时，以真实页面核对结果为准。

## D.3 结果栏注释来自哪里

建议在变量、参数、输出 connector 和复合接口成员的声明上写准确的 string-comment：

```modelica
parameter Modelica.Units.SI.HeatCapacity C=1200 "节点等效热容";
Modelica.Blocks.Interfaces.RealOutput temperature(unit="K") "节点温度";
Real internalTemperature(unit="K", start=293.15, fixed=true) "热容内部温度状态";
```

这是语法说明，不要求对既有状态再声明一份输出。具体结果描述还取决于工具、保存配置、变量别名和优化处理。更新源注释后应重新翻译并运行，新的结果元数据才可能带上新描述；旧 MAT 不会因为修改 `.mo` 而自动重写。没有目标软件或结果时，不声称“所有变量树已显示中文”。

**仅注释维护不改变** unit、displayUnit、min/max、start/fixed、HideResult、Evaluate、Inline、experiment、结果过滤器、输出周期和实际变量。CSV 说明表只是辅助导航，不是生成一套新的仿真变量。

## D.4 安全写回与生成器防回退

先读取全部类，包括单文件中的嵌套 connector、record、function 和短类定义；按具体 string-comment 与 Documentation 的语法范围修改，不能全文件替换引号内容。Documentation 内 `<html>`、链接、表格、许可与数学文本保留；删除最后图元的逗号问题与删 HTML 是两类操作，不混在同一宽泛正则里。

生成器若重新写入 `.mo`，应同步使用当前文档目录和模板。对已固定接口的生成文件，可以附带当前逐连接的已审核颜色表：只修改真实连接的 `Line.color`；拓扑发生变化而颜色表未更新时停止这部分自动写回，不能猜新端点。生成器的数学输入、单位转换、曲线插值和初态算法保持独立，文档后处理不得改变它们。

## D.5 辅助补丁白名单

| 变更模式 | 可以豁免的内容 | 始终保护的内容 |
|---|---|---|
| DOCUMENTATION_ONLY | Documentation、指定类/字段 string-comment、明确的根发布元数据 | 方程、算法、普通字符串常量、声明类型、接口、所有非文档注解 |
| CONNECTION_COLOR_ONLY | 实际 connect 的 Line.color | connect 两端、Line.points/宽度/箭头、Icon/Diagram 装饰图元 |
| 本次组合辅助维护 | 上面两项加用户明确的根版本变更 | 参数、状态、初始化、介质、实验、结果配置、资源和工作簿数据 |
| 全图形维护 | 仅用户授权的 Icon/Diagram/Placement/Line 图形范围 | 不因此豁免 experiment/Evaluate/Inline 或其他求解相关注解 |

对应源级检查只是一种词法保护检查，不是完整编译器证明。所有未支持语法或未解析继承保持待查；新旧源码保护 token 一致可以支持“限定范围未改”的结论，但不冒称本次已完成 GUI 或仿真验证。
