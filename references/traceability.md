# v0.9 追溯与历史索引

当前主规范为M01—M36（26R/9S/1F）；新增36项来源使用U-A01—U-H05，见[release_mapping.md](release_mapping.md)。以下v0.8调整和G01—G136只保留历史去向，不叠加执行旧要求。

# 版本与条号连续性

v0.8 将 v0.7 过于概括的角色描述展开为明确合同。M01—M36 编号继续沿用，M05 和 M08 的角色/边界要求由建议恢复为必须；其余主条目等级保持。目录、名称风格、传感器实现、说明和美术画法仍按建议处理。

## 当前修订

| 内容 | v0.8 做法 |
|---|---|
| 白箱 | TB/SB/AB 统一适用 M07，不是可选的“严格模式”；逐项规定声明、绑定、equation、algorithm、初始化、继承和上下文 |
| 静态模板 | 允许只含 connect 且可确定展开的参数化连接；普通行为分支仍下沉。相比早期一律禁用语法，以有效实现核对 |
| BU/LU | 内聚行为、运行子实例和库内部层次分别检查，不用命名规避角色 |
| 名称 | 类说明仅放中文用途，浏览器提供英文类名，避免重复 |
| Documentation | 不再生成通用连接统计/仿真查看教程/辅助更新免责声明，真实使用边界与许可保留 |
| 线色 | MSL 及派生原色；自定义整体主色；成员按实际类型；不豁免其他图形 |
| 品牌 | 原 MOSAIC LOGO、白底蓝色文档；不将文档蓝套到物理接口 |
| 证据 | 本工具测试与模型求解分开，未做的编译/GUI/物理验证不声称通过 |
